# CS5180 MADDPG Cooperative Transport

Starter repository for:

**Learning Decentralized Force-Feedback Coordination for Multi-Robot Cooperative Transport with MADDPG**

## Initial scope

1. Reproduce the directional MADDPG vs. independent-DDPG result on MPE2 `simple_spread`.
2. Build a custom PettingZoo Parallel API spring-coupled transport environment.
3. Compare MADDPG, independent DDPG, and a proportional force-feedback controller.
4. Test force-observation noise and action deadzones.

## Recommended environment

- Python 3.10
- PyTorch with CUDA support
- PettingZoo
- MPE2
- NumPy
- TensorBoard
- Matplotlib
- pytest

MPE environments have moved from `pettingzoo.mpe` to the maintained `mpe2` package. The custom
environment will still use the PettingZoo API.

## Windows PowerShell setup

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\setup_windows.ps1
```

Activate later with:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the CUDA-enabled PyTorch build using the command generated by the official PyTorch
"Start Locally" selector for Windows + Pip + your supported CUDA platform. Then run:

```powershell
python scripts\check_setup.py
python scripts\smoke_test_mpe.py
pytest
```

## Ubuntu/Linux setup

```bash
chmod +x scripts/setup_linux.sh
./scripts/setup_linux.sh
source .venv/bin/activate
```

Install the CUDA-enabled PyTorch build using the command generated by the official PyTorch
"Start Locally" selector for Linux + Pip + your supported CUDA platform. Then run:
